    Acceptable use policies and model cards: Publication of model cards for significant new models describing capabilities, limitations, evaluations, and intended use cases.

    Relocated. The framework no longer has this text. The source coding records a counterpart in a companion document or a non-binding section.

    Why this status (source coding): No v3.0 sentence commits to publishing model or system cards; System Cards are named only as a vehicle for Risk Report discussions in 3.1.

    Developer's account: The developer published an account. It does not identify this change.
